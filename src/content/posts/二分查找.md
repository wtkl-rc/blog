```
class Solution {
    public int search(int[] nums, int target) {
        if(nums == null || nums.length == 0  ){
            return -1;
        }
        int left = 0;
        int right = nums.length-1;
        while(left<=right){
            int mid = (left + right) >>> 1;
            if(nums[mid]<target){
                left = mid+1;
            }else if(nums[mid]>target){
                right = mid-1;
            }else{
                return mid;
            }
        }
        return -1;
    }
}
```
二分查找要注意的一些点：
- 首先是left = mid+1
如果不这么写，写成left = mid，那么在 left = 1，right = 2 时，（left+right）/ 2 = 1 = mid ，nums[mid] < target ,那么left依然等于1
此时会陷入循环，这样区间不会收缩，所以要left-1
- 第二个就是（left+right）/ 2 = 1 = mid
这样写会出现什么问题呢，如果left和right很大，那么就会超出int的范围，出现整数溢出，int mid = (left + right) >>> 1;这里巧妙地运用了位运算，更快。
- （left+right）/ 2 = 1 = mid为什么不能写在if里面，其实是可以写，能通过，但是不好不符合规范
# 递归写法
注意两个事项
1. 基线条件，就是终止条件，直接返回结果，不再递归，防止无限循环。
2. 递归条件，将问题分解为规模更小的子问题，通过调用自身来求解，并组合结果。
# 两数之和
```
import java.util.HashMap;
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer,Integer> map = new HashMap<>();
        for(int i = 0;i<nums.length;i++){
            int mid =target - nums[i];
            if(map.containsKey(mid)){
                return new int[] {map.get(mid),i};
            }
            map.put(nums[i],i);
        }
        return new int[0];
    }
}
```
