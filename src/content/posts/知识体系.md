# Iterator
1. **统一遍历接口**：无论集合是 `List`、`Set` 还是自定义集合，只要实现 `Iterable` 接口（返回 `Iterator`），就能用相同的迭代器逻辑遍历；
2. **安全修改集合**：遍历过程中可通过迭代器的 `remove()` 方法删除元素，避免 `foreach` 直接修改集合导致的 `ConcurrentModificationException`；

## jwt
JWT 全称 **JSON Web Token**，是一种**轻量级、自包含的跨域身份验证与信息传递规范**，它以 JSON 格式封装数据，通过数字签名保证数据的完整性和不可篡改性，无需在服务器端存储会话状态，非常适合分布式系统、前后端分离架构的身份认证和数据传递场景。
1. 第一部分：头部（Header）
2. 二部分：载荷（Payload）
3. 第三部分：签名（Signature）

# RedisTemplate 中opsForValue()和boundValueOps有什么区别

**opsForValue()**：

用途：获取一个`ValueOperations`接口对象，该对象可用于执行 Redis 字符串类型的各种操作。

特性：每次操作都要明确指定键。

示例：

```
ValueOperations<String, String> valueOps = redisTemplate.opsForValue();
valueOps.set("key", "value");
String value = valueOps.get("key");
```

**boundValueOps(key)**：

用途：获取一个和特定键绑定的`BoundValueOperations`接口对象。

特性：后续操作会自动作用于绑定的键，无需重复指定。

示例：

```
BoundValueOperations<String, String> boundOps = redisTemplate.boundValueOps("key");
boundOps.set("value");
String value = boundOps.get();
```

**区别：**

当你只使用一次时就用opsForValue需要多次使用就用boundValueOps
